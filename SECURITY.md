# Security reports

Use [GitHub private vulnerability reporting](https://github.com/TELOS-Labs-AI/telos-verify/security/advisories/new)
for security-sensitive findings. On this repository's Security page, select
**Report a vulnerability**. If that option is unavailable, it needs to be enabled
by a repository owner; keep sensitive details out of public issues.

Include the commit, OS and Python version, exact command, a minimal reproducer,
expected and observed exit status and output, and the relevant check id.
Do not include private keys or confidential input.

For ordinary behavior or documentation findings, use the
[finding issue template](https://github.com/TELOS-Labs-AI/telos-verify/issues/new?template=finding.md).
See [REVIEWING.md](REVIEWING.md) for the verifier's scope and limits.
